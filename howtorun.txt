================================================================
  HOW TO RUN - Store (Laravel + React + Docker)
================================================================

STEP 1 - Start all containers
----------------------------------------------------------------
docker compose up -d

Wait until all 5 containers are running:
  - store-nginx-1
  - store-php-1
  - store-node-1
  - store-mysql-1
  - store-phpmyadmin-1

Check status anytime with:
  docker compose ps


STEP 2 - Install dependencies (first time only)
----------------------------------------------------------------
docker compose exec php composer install
docker compose exec php npm install


STEP 3 - Run database migrations (first time only)
----------------------------------------------------------------
docker compose exec php php artisan migrate --seed

  If asked "run in production?" type: yes


STEP 4 - Fix storage permissions (only if you see permission errors)
----------------------------------------------------------------
docker compose exec php chown -R www-data:www-data /var/www/html/storage /var/www/html/bootstrap/cache
docker compose exec php chmod -R 775 /var/www/html/storage /var/www/html/bootstrap/cache


STEP 5 - Set up PayPal Sandbox credentials (first time only)
----------------------------------------------------------------
1. Go to https://developer.paypal.com/dashboard/applications/sandbox
2. Create a new app (or use the default sandbox app)
3. Copy the Client ID and Secret
4. Paste them into app/.env:
     PAYPAL_CLIENT_ID=your_client_id_here
     PAYPAL_SECRET=your_secret_here
5. Clear the config cache:
     docker compose exec php php artisan config:clear


STEP 6 - Start the Vite frontend   KEEP THIS TERMINAL OPEN
----------------------------------------------------------------
docker compose exec php npm run dev

You should see:
  VITE ready in xxxx ms
  Local: http://localhost:5171/

================================================================
  TEST PAYPAL PAYMENT
================================================================

1. Go to http://localhost:8001 and click "Buy Now" on any product
2. Fill in your name and email
3. Click the PayPal button
4. Log in with your PayPal sandbox buyer account:
     - Find credentials at: Developer Dashboard > Sandbox > Accounts
     - Use the "Personal" (buyer) account email and password
5. Approve the payment in the PayPal popup

The admin payments page updates live without refreshing:
  http://localhost:8001/admin/payments


================================================================
  STOP EVERYTHING
================================================================

  docker compose down
